---
name: Public topic tag review
description: Privacy and approval policy for public lesson discovery tags.
---

Public lesson tag backfills must use only public titles and rendered public content, never the original teacher request or student records. Suggestions require a preview and individual manual review before writing; do not run automatic bulk tagging.

**Why:** The user explicitly requested a cautious reviewed backfill, and teacher requests can describe real students even when the generated lesson is public.

**How to apply:** Keep future suggestion sources allowlisted to public fields. New generation or classification tools must not bypass the review requirement without explicit approval of a changed policy.
